## [x] เฟส 1: ไกด์ส่องพระ (ผู้เล่นบ่นว่า "บางองค์ดูไม่ออกเลยว่าปลอมตรงไหน")

1. **โหมดเทียบองค์ครู** (ปุ่ม "เทียบ" ในแถวเครื่องมือ)
   - แบ่ง stage 2 ฝั่ง ซ้ายคือองค์ที่ส่อง ขวาคือองค์ครู (spec ของ model, cond 100) บนมือถือแนวตั้งแบ่งบน-ล่าง
   - ใช้ renderer เดียว วาด 2 ครั้งด้วย setViewport/setScissor ห้ามสร้าง WebGL context เพิ่ม
   - หมุน ซูม พลิก ส่อง ขยับพร้อมกันทั้งสององค์ มีป้าย "องค์ที่ส่อง" / "องค์ครู (ของแท้)"
   - ใช้ได้ทั้งหน้าร้าน ตู้พระ และส่องพระประจำวัน
2. **เช็กลิสต์จุดสังเกต**: แผงพับได้ แสดง TELLS ของรุ่นนั้น ผู้เล่นเลือก ✓ ตรง / ✗ ไม่ตรง / ? ไม่แน่ใจ (เกมไม่ช่วยตอบ) ถ้ากด "ไม่เอา" โดยติ๊ก ✗ ข้อที่ผิดจริง ให้นับเหมือนชี้จุดเก๊ถูก ล้างเมื่อเปลี่ยนองค์
3. **ถามอาจารย์**: วันละ 3 ครั้ง ซื้อเพิ่มครั้งละ ฿2,000 × เลเวล
   - ถ้าเก๊: บอกบริเวณกว้าง ๆ ("ลองดูที่ฐานนะ") และไฮไลต์บริเวณนั้นบนองค์พระ 2 วินาที (วงแสงสีทองกะพริบ)
   - ถ้าแท้: "อาจารย์ดูแล้ว ไม่เห็นอะไรผิดสังเกต" มีโอกาส 15% ตอบว่า "ไม่แน่ใจ"
   - ไม่ฟันธงว่าแท้หรือเก๊ตรง ๆ
4. **ความยากไต่ระดับ**
   - Lv.1–2: ของเก๊ผิดแบบเห็นชัด: ตัวเลขต่าง ≥ 2 (dots ต่าง ≥ 4), ห้ามผิดแค่ grain อย่างเดียว, ต้องผิดอย่างน้อย 1 จุดที่เห็นจากด้านหน้า
   - Lv.3–4: ผสม
   - Lv.5+: ผิดละเอียดได้ (ต่าง 1, grain, น้ำหนัก, UV, พิมพ์ย่อย)
5. **ทำจุดเล็กให้เห็นชัดขึ้น**: pores และ crackle เข้มและลึกขึ้นราว 1.5 เท่า และต่างจาก smooth ชัดเมื่อส่อง, เกศสั้นกับยาวต่างกันมากขึ้น, ขอบตัดกับมน และหนากับบางต่างกันชัดเมื่อมองด้านข้าง
6. **เฉลยพร้อมภาพตอนสรุปวัน**: องค์ที่โดนหลอกหรือปฏิเสธผิด แสดงภาพเทียบเล็ก (องค์นั้นกับองค์ครู) พร้อมระบุจุดที่ผิด เช่น "กลีบบัว 6 กลีบ (ของแท้ 7)"
7. **บทเรียนเริ่มเกม**: เกมใหม่ ลูกค้า 3 คนแรกเป็น "อาจารย์พาส่อง" มีลูกศรสอนทีละขั้น: หมุนดูหลัง → ดูข้าง → ส่อง → เทียบ → ตัดสินใจ ข้ามได้ และเปิดดูใหม่ได้จากเมนู ≡

## [x] เฟส 2: พระหลากหลายขึ้น

1. **ทำ MODELS แบบ data-driven**: รุ่นหนึ่ง = shape (รูปทรง) + pose (ปาง) + mat (เนื้อ) + finish (งานผิว) + spec ของจุดสังเกต เพื่อให้เพิ่มรุ่นใหม่ได้ง่ายโดยแก้แค่ข้อมูล
2. **รูปทรงใหม่** (outlinePts + ตำแหน่ง FIG): กลม, ใบโพธิ์ (หยดน้ำกลับหัวปลายแหลม), กลีบบัว, เม็ดขนุน (รีแหลมหัวท้าย), สี่เหลี่ยมชิ้นเล็ก, เหรียญหยดน้ำ, เหรียญใบเสมา
3. **ปางใหม่** ใน drawFigure:
   - ปางยืน (ยืนตรง แขนแนบลำตัว)
   - ปางลีลา (ก้าวเดิน ขาหน้าเยื้อง มือยกระดับอก)
   - ปางนาคปรก: นาคแผ่พังพานเหนือศีรษะ จุดสังเกตใหม่ `nagaHeads` (5 / 7 / 9 เศียร)
   - รูปเหมือนพระสงฆ์ชรา (สมมติ ไม่อิงบุคคลจริง): ครึ่งองค์ ใบหน้ามีรอยย่น จุดสังเกตใหม่ เช่น ย่าม/ลูกประคำ
4. **เนื้อใหม่** (MATS): ทองคำ, นวโลหะ (ทองอมชมพู มีจุดหลายเฉด), ชินตะกั่วสนิมแดง, ผงใบลาน (ดำ), ผงว่าน (เขียว/ชมพูอ่อน), กระเบื้องเคลือบ, ไม้แกะ (ลายเสี้ยนไม้)
5. **งานผิว (finish)** เป็นจุดสังเกตได้:
   - ลงรักปิดทอง: ชั้นรักสีดำ ทองหลุดลอกตามจุดสูง
   - ลงยา: เหรียญมีสีเคลือบแดง/เขียว/น้ำเงินในร่อง
   - กะไหล่ทอง: ทองบาง ๆ สึกที่จุดสูงจนเห็นเนื้อใน
   - คราบกรุ: ไขขาวและคราบดินตามร่อง สำหรับพระกรุเก่า
6. **เครื่องรางทรง 3D ใหม่** (ไม่ใช่แผ่นแบน) ปรับระบบหมุน ส่อง เทียบ ชี้จุดเก๊ ให้รองรับ:
   - พระกริ่ง/พระบูชาองค์เล็ก: โมเดลลอยตัว (LatheGeometry ฐาน + primitives) จุดสังเกต: ตอกโค้ดใต้ฐาน, รอยตะเข็บหล่อ, เสียงเขย่า (ปุ่ม "เขย่า" เล่นเสียงด้วย Web Audio ของแท้เสียงใสกังวาน ของเก๊เสียงทึบ)
   - ตะกรุด: ทรงกระบอกม้วนจากแผ่นโลหะ เห็นจำนวนรอบม้วนที่ปลาย มีเชือกถัก จุดสังเกต: จำนวนรอบ, สีเชือก, ลายถัก
   - เบี้ยแก้: เปลือกหอยเบี้ย (ทรงรีนูน มีร่องฟันด้านล่าง) อุดชันโรง ปุ่ม "เขย่า" ได้ยินเสียงปรอทไหล จุดสังเกต: สีชันโรง, ลายถักหุ้ม, เสียง
7. **กรอบพระ**: ลูกค้าบางคนนำพระใส่กรอบมา (ทอง / เงิน / สแตนเลส / อะคริลิกกันน้ำ) กรอบบังขอบและความหนา ต้องกด "ถอดกรอบ" ก่อนจึงดูขอบได้ (ลูกค้าความอดทน −1) กรอบทองเพิ่มมูลค่าขาย และร้านมีบริการ "เลี่ยมกรอบ" ในตู้พระ
8. **พิมพ์ย่อย/บล็อก**: แต่ละรุ่นมี 2–3 พิมพ์ย่อย (พิมพ์ใหญ่ / พิมพ์เล็ก / พิมพ์หน้าแก่, เหรียญบล็อกแรก / บล็อกสอง) ต่างกันด้วยจุดเล็กที่ตั้งใจ (เช่น ขีดใต้ฐาน จุดเหนือเศียร) ราคาต่างกันมาก ลูกค้าบางคนอ้างพิมพ์ผิด (พิมพ์ธรรมดาอ้างเป็นพิมพ์นิยม) ซึ่งไม่ใช่ของเก๊ แต่ถ้าเชื่อจะจ่ายแพงเกิน
9. **ความหายาก**: ทั่วไป / หายาก / หายากมาก / ตำนาน แสดง badge สี รวมอย่างน้อย 24 รุ่น กระจายทุกเลเวล วัดสมมติจากหลายภาค (เหนือ อีสาน กลาง ใต้) แต่ละภาคมีสไตล์ประจำ เช่น เหนือ = เนื้อดิน + ลงรัก, ใต้ = ตะกรุด / เบี้ยแก้
10. **สมุด**: แบ่งหมวด (พระเครื่อง / เหรียญ / พระกริ่ง / เครื่องราง) มีช่องค้นหาและตัวกรองตามภาค ความหายาก และเลเวล พร้อม "สมุดสะสม" ติด ✓ รุ่นที่เคยครอบครองแท้
11. **ประสิทธิภาพ**: แคช geometry และ texture ที่ใช้ซ้ำ และเช็กว่ามือถือยังลื่น

## [x] เฟส 3: เป้าหมายหลัง Lv.6 (ผู้เล่นบ่นว่า "ถึง Lv.6 แล้วตัน มีแต่เก็บเงิน")

1. **บารมี ★1–★10**: XP ที่เกิน Lv.6 แปลงเป็นดาว แต่ละดาวได้ฉายาใหม่และโบนัสเล็ก ๆ (ลูกค้ารอนานขึ้น, ราคาขาย +2%) HUD แสดงดาวแทนแถบ XP
2. **ตามล่าพระในตำนาน 5 องค์** (ปลดล็อก Lv.6)
   - 5 รุ่นสมมติที่ไม่มีในสมุด แต่ละองค์ต้องเก็บเบาะแส 3 ชิ้น
   - เบาะแสได้จาก: ลูกค้าเล่า (8% ต่อคน), ชนะดวล, ชนะประมูล, ซื้อจากเซียนรุ่นเก่า
   - ครบ 3 ชิ้น: เปิดองค์ครูในสมุด และองค์นั้นจะโผล่ในงานประมูลหรือหน้าร้าน โดยมีของเก๊เกรดเทพปนมาด้วย
   - ครบ 5 องค์: ได้ฉายา "ผู้พิทักษ์ตำนาน" และฉากจบพิเศษ
3. **ดวลส่องพระ**: เซียนคู่แข่ง 4 คน (ชื่อสมมติ นิสัยต่างกัน เช่น "เฮียตาเหยี่ยว" ส่องเร็ว, "อาจารย์ใจเย็น" ส่องแม่น) ท้าดวลวันละครั้ง พระ 5 องค์ 60 วินาที คู่แข่งจำลองความแม่นและความเร็ว ชนะได้เงินเดิมพัน + เบาะแส + ชื่อเสียง ชนะคนเดิมครบ 3 ครั้งได้ลูกค้าประจำของเขา แพ้เสียเงินเดิมพัน
4. **งานประมูล** (ทุก 5 วัน ปลดล็อก Lv.4): 3–5 องค์ต่อรอบ ส่องได้ก่อนประมูล คู่แข่ง AI มีงบและนิสัยต่างกัน บางคนเป็นหน้าม้าของคนขาย เคาะแบบจับเวลา 10 วินาทีต่อจังหวะ เพิ่มครั้งละ 5/10/20% อาจเจอพระในตำนานหรือของเก๊
5. **สาขาและลูกศิษย์** (ปลดล็อก Lv.6)
   - เปิดสาขาได้สูงสุด 3 แห่ง (ตลาดนัด / ห้าง / ออนไลน์) มีค่าเปิดและค่าเช่ารายวัน
   - ลูกศิษย์มีฝีมือ 30–90 (โอกาสตัดสินถูก) ซื้อขายเองอัตโนมัติ แสดงกำไรหรือขาดทุนในสรุปวัน
   - เพิ่มฝีมือได้ด้วยการจ่ายเงินสอน (+5) หรือให้ดูผู้เล่นส่อง (ชี้จุดเก๊ถูก = +1)
6. **พิพิธภัณฑ์พระ** (ปลดล็อก Lv.6, ฿5,000,000): ตู้จัดแสดงอัปเกรดได้ 4 → 12 ตู้ คะแนนจากความหายาก สภาพ รางวัล และชุดที่ครบตามธีม (เช่น ครบทุกพิมพ์ของวัดเดียว ครบทุกภาค) มีรายได้ค่าเข้าชมรายวัน
7. **นายกสมาคมเซียนพระ** (สมาคมสมมติ): ลงสมัครได้เมื่อ ★5+ เลือกตั้งทุก 30 วันในเกม คะแนนจากชื่อเสียง + ชนะดวล + คะแนนพิพิธภัณฑ์ + พระในตำนาน ชนะแล้วปลดล็อกฉากจบ "นายกสมาคม" และเล่นต่อได้
8. **หน้า "เป้าหมาย"** ในเมนู ≡ แสดงความคืบหน้าทุกข้อ ผู้เล่นจะรู้ว่าต้องทำอะไรต่อ

## [ ] เฟส 4: กล สายเทา บุญกรรม และฉากจบ

1. **ค่าบุญ (merit 0–100 เริ่ม 50) และค่ากรรม (karma 0–100)** แสดงใน HUD เป็นไอคอนเล็ก
   - สายขาวเพิ่มบุญ: ถวายวัด, คืนของให้ลูกค้าที่โดนหลอก, บอกผู้ซื้อตามจริง
   - สายเทาเพิ่มกรรมและลดบุญ
   - บุญสูงเหตุการณ์ดีเกิดบ่อยขึ้น กรรมสูงเหตุการณ์ร้ายเกิดบ่อยขึ้น
   - (ค่า heat ของรุ่นที่จัดสร้างยังแยกไว้ตามเดิม)
2. **กลที่คนอื่นเล่นใส่ผู้เล่น**
   - ใบรับรองปลอม: ลูกค้าแนบใบเซอร์ กด "ตรวจใบเซอร์" (฿500) ใบปลอมมีจุดผิดให้สังเกตเอง (เลขที่ซ้ำ ตราประทับเบลอ) แสดงเป็นภาพบัตรเล็ก
   - สลับองค์: หลังรับเช่า มีโอกาส 8% (Lv.3+) ที่องค์ที่ส่งมอบเป็นอีกองค์ มีขั้น "ตรวจรับของ" ให้หมุนดูก่อนจ่าย จับได้ได้เงินคืน + XP
   - คู่แข่งปล่อยข่าวว่าร้านขายของเก๊: ชื่อเสียงลดทุกวันจนกว่าจะแก้ข่าว (แสดงพระมีใบรับรอง 3 องค์ หรือจ้างทนาย)
   - หน้าม้าในงานประมูล มีพฤติกรรมให้สังเกต (เคาะทันทีทุกครั้ง, หยุดพอดีราคาประเมิน)
3. **สายเทาที่ผู้เล่นเลือกได้** (ปุ่มชัดเจน ขึ้นยืนยันทุกครั้ง)
   - แต่งผิวพระ: สภาพ +10–20 ตอนขายเลือก "บอกผู้ซื้อ" (ราคา −15%, บุญ +2) หรือ "ไม่บอก" (ราคาเต็ม, กรรม +10, โอกาสโดนจับได้ 25%)
   - ติดสินบนกรรมการประกวด: คะแนน +15 กรรม +20 โอกาสโดนแฉ 20%
   - จ้างหน้าม้าในงานประมูลตอนขายพระของตัวเอง: ราคา +20% กรรม +10
   - ปล่อยข่าวโจมตีคู่แข่ง: คู่แข่งอ่อนลงในการดวล 3 วัน กรรม +15
   - โดนจับได้: ชื่อเสียงลดหนัก ค่าปรับ และข่าวฉาวในสรุปวัน
4. **หน่วยปราบพระปลอม (สมมติ)**: ทุก endDay โอกาสเข้าตรวจ = กรรม/300 ของเก๊ที่รู้แล้วแต่ยังไม่ทิ้งถูกยึด ประวัติขายแบบ "ไม่บอก" ถูกปรับ ถ้ากรรม ≥ 90 ตอนโดนตรวจจบเกมแบบ "โดนจับ" ลดกรรมได้ช้า ๆ ด้วยทำบุญใหญ่หรือถวายวัด
5. **ฉากจบ** (เช็กเมื่อได้เป็นนายกสมาคม หรือครบวันที่ 120)
   - เซียนผู้ทรงธรรม: บุญ ≥ 80
   - เจ้าพ่อวงการพระ: รวยมาก กรรม 50–89 ไม่เคยโดนจับ
   - เซียนสายกลาง: กรณีอื่น
   - ตกอับ: เงินติดลบหนักต่อเนื่อง 10 วัน
   - โดนจับ: ตามข้อ 4
   - ผู้พิทักษ์ตำนาน: ครบพระในตำนาน 5 องค์ (จากเฟส 3)
   - แต่ละฉากเป็นหน้าสรุปสวย ๆ พร้อมสถิติ และปุ่มคัดลอกข้อความไปแชร์ หลังจบเลือก "เล่นต่อ" หรือ "เริ่มใหม่ (เก็บฉายาที่ปลดล็อกไว้)"
   - หน้า "สมุดฉากจบ" ในเมนู ≡ (ที่ยังไม่ได้แสดงเป็น ???)
6. ข้อความทั้งหมดเป็นโทนเกม ไม่ใช่การสอนวิธีโกงจริง และอัปเดตหน้าวิธีเล่น (ไม่ต้องเฉลยตัวเลขโอกาส)

# รอบ 4: กิจกรรมและฟีเจอร์ใหม่ (ผู้เล่นอยากให้มีอะไรทำนอกจากรับเช่าหน้าร้าน)

## [ ] เฟส 5: กิจกรรมนอกร้าน

1. **เดินสนามพระ** (เปิดวันเสาร์-อาทิตย์ในเกม หรือทุก 7 วัน)
   - หน้าแผนที่สนามพระ มี 6–8 แผง เป็นการ์ดภาพแผงพร้อมชื่อแม่ค้าสมมติและนิสัย
   - แต่ละแผงมีถาดพระ 12–20 องค์ แสดงเป็นกริดภาพเล็ก (thumbnail res ต่ำ ทยอยสร้างทีละองค์ ห้ามค้าง)
   - มี "พลังเดิน" 10 แต้มต่อรอบ: เปิดดู 3D ใช้ 1 แต้ม หมดแล้วต้องกลับร้าน
   - แต่ละรอบมี "ของหลุด" 1–3 องค์ซ่อนอยู่ (ของแท้ที่แม่ค้าดูไม่เป็นจึงตั้งราคาถูก หรือพิมพ์นิยมที่แม่ค้าคิดว่าพิมพ์ธรรมดา)
   - แผงเซียนขายแพงแต่แท้ บางแผงมีแต่ของเก๊ ต่อราคาได้ด้วยระบบเดิม
2. **ทริปต่างจังหวัด**
   - แผนที่ 4 ภาค (SVG สวย ๆ วาดตามขนาดจริง) เลือกเดินทาง ใช้เงินค่าเดินทางและ 2 วันในเกม (ระหว่างนั้นร้านปิด หรือให้ลูกศิษย์เฝ้าถ้ามีจากเฟส 3)
   - ที่ต้นทาง พระของภาคนั้นถูกกว่าปกติ 30% และมีงานวัดประจำภาค
   - มีเหตุการณ์ระหว่างทางแบบเลือกตอบ 1–2 เหตุการณ์ต่อทริป (เช่น เจอชาวบ้านมีพระเก่าในบ้าน, รถเสีย)
3. **ขุดกรุ** (เหตุการณ์หายาก ต้องมีความไว้ใจวัด ≥ 60)
   - "วัดบูรณะเจดีย์ พบกรุ" ผู้เล่นได้รับเชิญไปช่วย
   - มินิเกมขูดดินออกจากองค์พระ (scratch บน canvas ทับภาพพระ ใช้นิ้วหรือเมาส์) ขูดเร็วหรือแรงเกินไปองค์บิ่นและสภาพลด
   - ได้พระกรุพร้อมคราบกรุ (finish จากเฟส 2) ต้องแบ่งให้วัดตามสัดส่วน แบ่งน้อยความไว้ใจลด

## [ ] เฟส 6: ภารกิจและเรื่องราว

1. **กระดานออเดอร์ลูกค้า**: วันละ 3 งาน เช่น "หาพระเนื้อดิน ภาคเหนือ สภาพ ≥ 85 งบ ฿60,000 ภายใน 3 วัน ให้ลูกสาวพกไปสอบ" ส่งจากตู้ได้ค่าตอบแทนสูงกว่าราคาตลาดและได้ชื่อเสียง ส่งของเก๊แล้วโดนจับได้ ชื่อเสียงลดหนัก
2. **เนื้อเรื่องลูกค้าประจำ**: ตัวละครสมมติ 5 คน คนละ 3–5 ตอน ปลดล็อกตามวันและเงื่อนไข ตัวอย่าง:
   - ป้าบุญมีตามหาพระของสามีที่ถูกขโมยไป: ป้าบอกลักษณะเฉพาะ (รอยบิ่นตำแหน่งไหน รอยลายนิ้วมือด้านหลัง) ใช้ seed ของชิ้นเป็นเอกลักษณ์ ผู้เล่นต้องจำให้ได้เมื่อเจอองค์นั้นในสนามพระหรือหน้าร้าน
   - เด็กหนุ่มอยากเป็นเซียน มาขอเป็นลูกศิษย์ (เชื่อมกับลูกศิษย์ในเฟส 3)
   - เซียนเก่าที่เกษียณแล้ว ค่อย ๆ เล่าเบาะแสพระในตำนาน (เชื่อมกับเฟส 3)
   - แต่ละตอนมีบทสนทนาสั้น ๆ และตัวเลือกที่มีผลต่อบุญหรือกรรม (เชื่อมกับเฟส 4)
3. **ความสำเร็จ** 40 รายการ (เช่น ชี้จุดเก๊ถูก 50 ครั้ง, เจอของหลุด, เก็บครบทุกภาค) มีป๊อปอัปตอนได้ และหน้ารวมในเมนู ≡

## [ ] เฟส 7: ช่องทางขายใหม่และชีวิตในร้าน

1. **แชทเสนอพระ** (หน้าจอแบบแอปแชท ใช้ชื่อสมมติ ห้ามใช้ชื่อหรือโลโก้แอปจริง)
   - ลูกค้าทักมาเสนอพระ เห็นแค่รูป 2–3 รูป (render มุมคงที่ บางรูปเบลอ แสงจ้า หรือถ่ายเฉียง) และข้อความ
   - ตัดสินใจโอนเงินจากรูปได้เลย ราคาถูกกว่าหน้าร้าน แต่เสี่ยง: ของที่ส่งมาอาจไม่ตรงรูป หรือโดนโกงไม่ส่งของ (โอกาสขึ้นกับว่าดูรูปออกไหม)
   - พอของมาถึงวันรุ่งขึ้น ค่อยส่อง 3D ได้เต็มที่
2. **ไลฟ์ขายของในตู้**: ใช้ระบบไลฟ์เดิมของจัดสร้าง แต่เอาพระในตู้มาประมูลสด คนดูสุ่มเสนอราคา ผู้เล่นเลือกจังหวะปิดประมูล
3. **แต่งร้าน**: ตั้งชื่อร้าน ป้ายร้าน ฉากหลัง (แผงพื้น → ห้องแถว → ร้านในห้าง) ตู้โชว์ ผ้ากำมะหยี่หลายสี และไฟ ซื้อเป็นของตกแต่ง บางชิ้นเพิ่มลูกค้าเล็กน้อย ฉากหลังบน stage เปลี่ยนตามจริง
4. **แมวประจำร้าน**: รับเลี้ยง ตั้งชื่อ เดินไปมาบนหน้าจอ (SVG หรือ CSS ไม่ใช้ภาพจากเน็ต) ต้องให้อาหารทุกวัน บางวันคาบของเล็ก ๆ มาให้ นอนทับพระ หรือทำให้ลูกค้าอารมณ์ดี (อดทน +1)
5. **โจรขึ้นร้าน**: ถ้ามูลค่ารวมในตู้สูง มีโอกาสโดนขโมยตอน endDay ซื้อตู้เซฟ กล้องวงจรปิด หรือประกันพระเพื่อลดความเสี่ยง

## [ ] เฟส 8: โลกที่มีชีวิต โหมดเสริม และการแชร์

1. **ปฏิทินและเทศกาล** (30 วันในเกม = 1 เดือน): สงกรานต์ เข้าพรรษา ออกพรรษา ลอยกระทง ปีใหม่ ตรุษจีน แต่ละเทศกาลมีความต้องการพระต่างกันและกิจกรรมพิเศษ แสดงปฏิทินในเมนู
2. **ฟีดวงการพระ**: ฟีดโซเชียลในเกม โพสต์จากตัวละครสมมติ ข่าวลือ (จริงราว 60% บางอันคู่แข่งปล่อย) แนวโน้มราคา คู่แข่งโพสต์อวด อ่านแล้วได้ข้อมูลไปวางแผน
3. **กระดานราคา**: ราคาตลาดทุกรุ่นขยับรายวันตามข่าว เทศกาล และกระแส แสดงเป็นตารางพร้อมลูกศรขึ้นลงและกราฟเล็ก
4. **โหมดส่องเร็ว (Time Attack)**: เล่นได้ไม่จำกัด 60 วินาที ตัดสินแท้/เก๊ให้ได้มากที่สุด ถูกติดกันได้คอมโบ เก็บคะแนนสูงสุด และคัดลอกผลไปแชร์ได้
5. **การ์ดอวดพระ**: สร้างภาพโปสเตอร์ (canvas 1080x1350) ของพระองค์เด่นพร้อมชื่อร้าน ฉายา และสถิติ มีปุ่มดาวน์โหลด PNG และปุ่มแชร์ (Web Share API ถ้าเบราว์เซอร์รองรับ)
6. **รหัสแลกพระกับเพื่อน**: ส่งออกพระในตู้เป็นรหัสสั้น (modelId, spec, cond, seed + checksum) เพื่อนนำเข้าได้ องค์ที่ส่งออกหายจากตู้ และรหัสเดิมใช้ซ้ำในเซฟเดียวกันไม่ได้
7. **เพลงพื้นหลัง**: สังเคราะห์ด้วย Web Audio แนวเครื่องดนตรีไทย (ระนาด ฆ้อง) เบา ๆ วนได้ ปรับระดับเสียงเพลงกับเอฟเฟกต์แยกกันในเมนู
