# เซียนพระ จำลอง

เกมเว็บจำลองการเป็นเซียนพระ มีองค์พระ 3D หมุนได้ 360° แยกพระแท้/เก๊ ไต่เลเวล งานประกวดพระ และจัดสร้างพระกับวัด

## เล่นออนไลน์
https://sasikanphae.github.io/sian-phra/

ทุกครั้งที่ push เข้า branch `main` GitHub Actions จะ deploy ขึ้น GitHub Pages ให้อัตโนมัติ
(ครั้งแรกต้องตั้งค่าใน repo: **Settings → Pages → Build and deployment → Source: GitHub Actions**)

## รันเกมบนเครื่อง
ต้องเปิดผ่าน web server (ดับเบิลคลิก index.html ตรง ๆ จะไม่ทำงาน)

```bash
cd sian-phra
npx serve .                    # ถ้ามี Node.js
# หรือ
python3 -m http.server 8000    # ถ้ามี Python แล้วเปิด http://localhost:8000
```

## พัฒนาต่อด้วย Claude Code
1. ติดตั้ง Claude Code (ต้องมี Node.js 18+): `npm install -g @anthropic-ai/claude-code`
2. เข้าโฟลเดอร์โปรเจกต์แล้วพิมพ์ `claude`
3. Claude Code จะอ่าน `CLAUDE.md` เองอัตโนมัติ จึงรู้โครงสร้างเกมทันที สั่งงานเป็นภาษาไทยได้เลย

ตัวอย่างคำสั่ง:
- `เพิ่มพระรุ่นใหม่ "พระปิดตา วัดบ้านนา" เนื้อตะกั่ว ปลดล็อก Lv.4 พร้อมจุดสังเกตใหม่ "ยันต์ที่ฝ่ามือ"`
- `เพิ่มเสียงประกอบ ตอนรับเช่า พลิกพระ และตอนเลื่อนระดับ (สร้างเสียงด้วย Web Audio ไม่ต้องใช้ไฟล์)`
- `เพิ่มระบบภารกิจรายวัน เช่น "จับของเก๊ให้ได้ 2 องค์" ได้รางวัล XP`
- `ทำให้ลูกค้าบางคนเป็นเซียนคู่แข่งที่มาแย่งซื้อพระ`
- `เพิ่มตารางอันดับ และปุ่มคัดลอกผลงานไปแชร์`
- `ช่วยรีแฟกเตอร์ game.js แยกเป็นหลายไฟล์ (data, amulet3d, ui, state)`
- `เตรียมโปรเจกต์ขึ้น GitHub Pages`

เคล็ดลับ: สั่งทีละเรื่อง แล้วเปิดเกมทดสอบทุกครั้ง ถ้ามีอะไรผิดก็บอก Claude Code ได้เลย เช่น "บนมือถือปุ่มล้นจอ"
